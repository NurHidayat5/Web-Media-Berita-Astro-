# Blog Pribadi - Hidayat

## Deskripsi
Blog portfolio pribadi yang dibangun dengan Astro + Wix RSS Feed.
Artikel ditulis di Wix Dashboard, lalu di-fetch ke Astro via RSS Feed
untuk menampilkan blog dengan performa tinggi dan SEO optimal.

## Tech Stack
- **Framework:** Astro 5
- **CMS:** Wix (RSS Feed)
- **XML Parser:** fast-xml-parser
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
